# PicoCTF: Password Profiler Solution

An automated solution workflow to solve the **Password Profiler** challenge from picoCTF. This challenge demonstrates how personal details can be leveraged to generate targeted wordlists for credential cracking.

## Challenge Overview
The challenge provides a target profile (`userinfo.txt`), a target SHA-1 hash (`hash.txt`), and a verification script (`check_password.py`). The objective is to generate a custom dictionary file based on the profile data to find the matching password and reveal the flag.

## Prerequisites
* Python 3.x
* [CUPP (Common User Passwords Profiler)](https://github.com)

## Directory Structure
```text
.
├── check_password.py  # Provided validation script
├── hash.txt           # Target SHA-1 hash file
├── userinfo.txt       # Target profile information
└── README.md          # This documentation file
```

## Step-by-Step Execution

### 1. Extract Profile Information
Open `userinfo.txt` to gather the required parameters for the wordlist generator:
```bash
cat userinfo.txt
```
*Note down names, nicknames, birthdates, pet names, partners, company names, and related keywords.*

### 2. Generate the Custom Wordlist
Run CUPP in interactive mode and input the collected profile details when prompted:
```bash
cupp -i
```
When prompted by the utility, enable options for adding **random numbers** and **special characters** to ensure complete password coverage.

### 3. Stage the Wordlist File
The verification script expects a wordlist explicitly named `passwords.txt`. Rename or copy the output file generated by CUPP:
```bash
mv target_profile_name.txt passwords.txt
```

### 4. Execute the Verifier to Get the Flag
Run the python check script to test the custom wordlist against the target hash:
```bash
python3 check_password.py
```

Upon a successful match, the script will print the decrypted password and output the flag format (`picoCTF{...}`).
