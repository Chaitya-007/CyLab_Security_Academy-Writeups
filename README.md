# CyLab Write-ups

Short, practical write-ups of CTF challenges I solve on [CyLab Academy](https://cylabacademy.net) while building hands-on skills in cybersecurity, with a focus on SOC analyst work.

Maintained by **Chaitanya Asole** · [LinkedIn](https://www.linkedin.com/in/chaitanya-asole/)

## Purpose

- Keep a record of how I approach and solve problems, not just the answers.
- Practice explaining technical steps clearly, which is a core part of incident reporting.
- Build a visible learning trail across networking, forensics, web security, and more.

## How this repo is organized

Each top-level folder is a challenge category, and each challenge has its own folder with a `README.md` write-up:

```
<category>/
└── <challenge-name>/
    └── README.md
```

Categories follow the CyLab Academy categories (General Skills, Forensics, Web Exploitation, Cryptography, and so on). Browse the folders above to see what's been solved.

## What a write-up contains

Each write-up is kept short and follows the same shape:

1. **Problem**: what the challenge asked.
2. **Solution**: the steps and commands I used.
3. **Learned**: the main takeaway.

## Notes

- Flags are redacted (`picoCTF{*****}`). The method matters more than the answer.
- Write-ups are in my own words and reflect my understanding at the time.
- If you spot a mistake or a better approach, feel free to open an issue.

## Disclaimer

This repo is for learning purposes only. All techniques are practiced on intentionally vulnerable CTF platforms where permission is given. Never test them on systems you don't own or have explicit authorization to test.
